# MindFlow – Smart Productivity Platform

## Project Description
MindFlow is a simple frontend productivity application developed using HTML, CSS and JavaScript. It helps users organize daily tasks and ideas in one place.
MindFlow helps users organize tasks and ideas efficiently.
MindFlow is designed to improve daily productivity through task and idea management.

## Features
- Add and delete tasks
- Set Low, Medium and High priorities
- Mark tasks as completed
- Track total, completed and pending tasks
- Create and delete Mind Map ideas
- Save data using browser LocalStorage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Visual Studio Code
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Use the To-Do List and Mind Map features.
